# ⚡ 정전기 헌터 — FAB ESD 소탕전

FAB 전공정/후공정 라인에 발생한 정전기(ESD)를 이오나이저 봇으로 잡아먹는 아케이드 게임입니다.
서버 없이 브라우저만으로 동작하며, PC와 스마트폰 모두 지원합니다.

## 🎮 플레이 방법

- **PC**: 방향키 또는 WASD로 이동
- **모바일**: 화면 아무 곳이나 터치한 뒤 드래그 (가상 조이스틱)
- ⚡ **정전기** +1점 · 🌟 **대전 보너스** +5점
- 🔴 **ESD 서지**에 닿으면 −3점 (잠시 무적)
- **90초** 동안 가장 많은 정전기를 제거한 엔지니어가 승리!

## 👥 멀티플레이 (최대 7명)

별도 게임 서버 없이 **PeerJS(WebRTC P2P)** 로 연결됩니다.

1. 한 명이 **방 만들기** → 5자리 방 코드 생성
2. 나머지 플레이어가 **방 코드 입력 → 참가**
3. 호스트가 **게임 시작**

호스트가 스파크·점수·충돌을 판정하는 호스트 권위(host-authoritative) 방식입니다.
혼자 플레이 모드도 있습니다.

## 🚀 실행

정적 파일 하나(`index.html`)가 전부입니다.

- **GitHub Pages**: Settings → Pages → Branch를 `main`으로 설정하면 배포 완료
- **로컬**: `index.html`을 브라우저로 열기만 하면 됩니다 (멀티플레이는 HTTPS 환경 권장)
